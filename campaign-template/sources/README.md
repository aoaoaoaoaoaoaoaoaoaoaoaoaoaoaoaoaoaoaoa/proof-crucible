# Committed source synopses

This directory contains public-safe projections of works used by the campaign.
It contains no source artifacts. Exact retained materials, local neutral
sidecars, digests, and the local catalogue live in the ignored `references/`
corpus.

Each synopsis uses this shape:

```markdown
# <authors> (<year>): <title>

**Citation.** <full citation>

- Work identity: <DOI, arXiv identifier, or stable identity>
- Canonical source: <public URL>
- Version and status: <exact version; publication/preprint/etc.>
- Synopsis basis: <full text, bounded sections, abstract only, etc.>

## Synopsis

<Neutral account of scope, results, hypotheses, methods, and limitations.>

## Source assessment

<Corrections, defects, disputes, supersession, or unresolved hazards.>

## Project use

<Exact campaign definitions or obligations supported by this work.>
```
